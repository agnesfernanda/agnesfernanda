## 👋 Olá, eu sou a Agnes!

Estagiária de dados no **Banco Santander**, na área de **Recuperação de Crédito**, trabalhando com bases de inadimplência de cartão de crédito, empréstimos e financiamentos.

No dia a dia, extraio, trato e valido dados, acompanho KPIs e automatizo relatórios gerenciais. Gosto de transformar processos manuais em soluções práticas e de usar tecnologia para resolver problemas reais.

- 🎓 Graduanda em **Administração de Empresas** na **UNIFESP** (conclusão prevista para 2028)
- 💻 Cursando **Desenvolvimento Web Full-Stack** na Programadores do Amanhã (2026–2027)
- 📊 Iniciando estudos em **R**
- 🌎 **Inglês avançado**, com experiência no contato com fornecedores estrangeiros
- 🎯 Em busca de oportunidades como **Analista de Dados Júnior**
